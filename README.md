# 1C Quiz Advanced v2

Практический интерактивный тест по теме Linux/SRE/DevOps в экосистеме 1C для встраивания в публикацию https://infostart.ru/1c/articles/2778482/ на infostart.ru.

## Соответствие правилам публикации

- В репозитории нет рекламы, реферальных ссылок и скрытого сбора данных.
- Ссылка на GitHub тематически связана с материалом статьи.
- В текст статьи добавлено пояснение, что интерактивный тест размещен во внешнем репозитории.

## Структура репозитория

- index.html - интерактивная страница викторины, публикуемая через GitHub Pages.
- article-code.html - безопасный HTML-шаблон для вставки в статью на infostart.ru.
- .nojekyll - отключает Jekyll, чтобы GitHub Pages отдавал файлы как обычный статический сайт.
- LICENSE - лицензионный файл репозитория.

## Шаблон статьи для Infostart

Файл article-code.html используется как портал между публикацией на Infostart и внешней интерактивной страницей.

Внутри шаблона:

- есть обычный статичный текст статьи с inline-оформлением;
- нет тегов script и style;
- нет JavaScript-обработчиков вроде onclick или onload;
- интерактивная часть подключается только через iframe на GitHub Pages;
- оставлена резервная ссылка на прямое открытие теста, если iframe не загрузится.

Такой формат нужен потому, что редактор Infostart может очищать или искажать полный HTML-документ с head, body, style и script. Поэтому исходник викторины размещается отдельно в index.html, а в статью вставляется только article-code.html.

## Порядок публикации

1. Обновить index.html или article-code.html локально.
2. Выполнить commit и push в ветку main репозитория.
3. Дождаться, пока GitHub Pages опубликует свежую версию сайта.
4. Открыть article-code.html и скопировать его содержимое целиком.
5. В редакторе Infostart перейти в режим Source и вставить шаблон в текст статьи.
6. Сохранить черновик и проверить предпросмотр публикации.

## Практические замечания

- Если в предпросмотре Infostart появляется старый 404, помогает жесткое обновление страницы редактора.
- Если под викториной появляется лишняя пустота, корректируется только высота iframe в article-code.html.
- Если модерация не принимает слишком "технический" блок, можно оставить article-code.html как основной контент статьи, а интерактивный тест вынести в середину или конец материала.
